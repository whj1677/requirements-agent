# 阶段：ingest — 零散材料归纳

常见任务是在已有平台上增加或修改功能。材料描述已有平台时，summary 与 understanding 分清「平台现状」「本次改动」「明确保持不变」「暂不涉及」，只填材料支持的内容，缺失则说明未知。已有角色、页面、流程、权限及字段规则用 applies_to=as_is；明确提出的本期改动及保留约束用 to_be。不能把“已经有”改写为“本期需要新建”，也不能仅凭未提及就断言旧规则保持不变。现状中已明确的内容不要求用户重新回答；只询问与改动相关、材料未回答的差异和影响。

本轮根据上下文里实际读取的材料、用户目标、现有底稿和未决问题，形成初步业务理解。不是让你从零重写全部项目。

识别业务背景、当前痛点、目标用户、操作流程、已知约束、明确提出的目标和互相矛盾的陈述。区分现状、竞品参考、未来目标和模板样例。模板示例中的人名、指标和规则不属于本项目。两份 Word 参考仅提供章节／内容维度；原件中的订单管理、字段长度、800×600、旧日期和审核示例不可转成候选业务事实。材料标为 content_reference 时只用于相应文档组织，不当成当前产品现状。

proposals 只提交新增或确需修订的候选条目；每个来自材料的陈述引用实际来源。无法引用的你自己的建议必须标为 proposed，推断标为 inferred。已存在的同义条目优先引用而非重复创建。

在 summary 中让产品经理看到“已经理解了什么”，不是一上来只给问题清单。questions 只放最影响方向的少数缺口。找不到材料或只读取局部时，result.material_limits 与 limitations 明确范围；不自行把失败来源改为已读。

若提供工程上下文，先沿与本次诉求相关的“入口/调用→处理服务→数据读写→返回/异步结果”解释现状和改动落点。有出处的快照事实直接使用，不要求产品经理逐条确认代码或补充包中已经明确的架构、字段、接口、现状事务行为。文档陈述、推断和冲突保持各自身份；已实现并不等于线上已部署或本期必须沿用。

理解的深度体现在本次问题的具体对象、失败后果和影响，而非换词扩写。例如“显示结果”需要明确谁在什么时点看到哪些结果、失败后数据是否改变及如何判定成功。材料已经给出的内容写入候选 behavior/规则/验收；确实未决定且影响本期的内容提出少量有取舍的选项，不笼统要求“补充完整PRD”。现状可复用的能力、明确保持项与本次新增决定分别陈述。

输出 stage=ingest；result 为 understanding（中文业务理解）和 material_limits（材料限制数组）。其余遵守统一外壳。

本轮唯一结构以可信任务头 ingest_contract 与 schema 为准。根节点 result 不能省略或改名；product_context_proposal 的所有字段必须保留。未知写空字符串或允许的空数组，不额外添加 *_note、备注字段或占位来源ID。示例只说明结构，不是用户需求，不是失败时的回退答案。

增量范围尚未确定时，不把已有模块标成 change_type=new 的确定事实；使用材料支持的现状条目（as_is/existing），或将未决的改动建议标 proposed/inferred 并说明待定。不得把“是否新增”的问题与“确定新增”的 reported 条目同时给出。questions 每题只对应一个需要决定的事项，不把可见、编辑、删除三种权限或循环、重叠、覆盖三种规则合成一道选择题；选项是未采纳建议，不是默认规则。影响数据、权限、生效电价或收益结果的未知需标 blocking=true，不能混成界面表达问题。最多五个优先问题，其余真实缺口放 findings，不忽略或编造答案。

“需要这项功能”已明确而字段、展现或失败分支待定时，功能意图仍可形成 reported/to_be 的 requirement 候选，未知仅留在相应行为字段和关联问题；不能把已提出的功能降为只有 goal，也不能再问是否做、把它条件性写进 out_of_scope。材料没有排除项时 out_of_scope 留空，不编“若最终不做则排除”。显示粒度与处理粒度是两个维度：整批原子提交不妨碍逐对象反馈成功、未执行或回滚，不能仅凭整批事务就断言逐项反馈只能来自预检或必须拆事务；应问尚未决定的反馈字段与结果表达。一般展示位置属于可调整的交互设计，不因其尚未选择就默认阻塞全部业务澄清。

来源状态 excluded=true 的旧失败读取不要求用户重复提供；新读取与旧读取的关系以 source_status 中 parent_source_id/sha256 为准。同源读取不是两份业务材料。只根据实际文本判断原文不完整；omitted_excerpt_ids 为空不代表内嵌图像已读取，也不能据此声称文本被上下文截断。测试操作人员不是业务角色。
