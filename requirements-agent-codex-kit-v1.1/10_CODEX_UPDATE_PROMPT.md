本次要求：生成的 Word 需求文档，以交付包中的 `references/产品需求文档PRD模板(1).docx` 和 `references/百度产品需求管理文档（MRD）模板(1).docx` 作为参考模板。**重点参考章节结构和内容维度，不是要求版式复刻、标题逐字相同、固定章数或逐格套填。**不要复制样例业务规则、旧作者／日期／审批签名、公司标识或静态页码。

3. 同一文档类型的 MD／DOCX 从同一个内容对象导出；PRD／MRD 使用同版底稿，规则不矛盾。原型按实际 UI 版本绑定到“功能原型／页面布局”，不要将纯描述冒充已嵌入的图。
4. 同步更新文档结构、章节引用、导出器、提示词装配与版本记录，不只做提示词改动。模型响应外壳使用 Schema 1.1；wireframe 内部 Schema 仍为 1.0。若工程已持久化 1.0 数据，实现显式读取兼容或迁移，保留历史哈希／审批，不批量重写旧记录。
