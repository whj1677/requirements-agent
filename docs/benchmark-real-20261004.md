四条需求草稿的流程摘要：

1. **学习引导式答疑**：学生提出题目 → 助手提问和分步解释 → 等待回答 → 反馈并纠正误解；学生可要求放慢、简化或加深。入口、权限与具体纠错规则待定。
2. **学习资料引用与识别不足补救**：学生上传图片/PDF → 回答参考资料；识别不足时补充清晰版本、文字或具体位置 → 重新作答。失败判定及提示待定。
3. **基于个性化记忆的学习指导**：记忆可用且启用时参考历史信息，未启用时继续提供指导。是否提供记忆、学科隔离、存储及权限待定。
4. **语音输入与语音回应**：学生说话 → 助手语音回应，同时可看文字、切换文字输入及回看消息。语音形态、网络异常、重试和恢复待定。

仅有两条关联验收草稿：引导答疑的提问、反馈及讲解调整；资料引用及补充后重新作答。两者仍缺具体失败判据；**记忆和语音没有关联验收草稿**。

模型提出两个澄清问题：是否提供记忆及按学科隔离；语音采用听写还是实时通话。独立审查发现，前者合并了两项决定，后者遗漏按轮次语音这一选项；不能直接作为完整澄清清单。
