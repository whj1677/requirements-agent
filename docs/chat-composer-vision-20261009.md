## 使用与限制

1. 保存旧页面尚未提交的输入后刷新，进入“和助手聊需求”，在输入框按 Ctrl+V 粘贴图片。
2. 核对缩略图，可补充文字或移除；只粘图时输入框显示可修改的“请结合这些图片继续梳理需求。”。
3. 点“识别图片并发送”，在任务页核对图片及接收端后运行；识别完成进入同一访谈，历史消息保留附件缩略图。
4. 需要稍后继续时，切页选择“保存后离开”，会本地保存截图，不调用模型；同一浏览器页刷新可恢复待发送附件。尚未本地保存的 File 刷新后需重新粘贴，界面有离开保护和明确提示。响应丢失时依现有上传错误核对项目资料，本轮未增加文件上传幂等协议。
