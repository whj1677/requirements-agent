# 工作台界面更新 · 2026-10-27

按用户指定的 GitHub 浅色风格更新现有工作台，笔记本与 2K 展示同等优先。使用 Impeccable 的 Operate 流程，用户指定的主题覆盖早期探索方向。主题参考：https://primer.style/product/primitives/color/ 。

## 本次范围

- 白色内容、浅灰导航、细边框、蓝色链接与发送、绿色确认；统一系统字体与紧凑控件，不使用整页比例缩放。
- 收敛已有草稿的重复进入操作，AI 操作与普通查看、确认分开；表格把低频操作收进“更多操作”。
- 表格占据主要可用高度，确认栏保持可见。聊天记录单独滚动，输入区参与正常布局，避免长对话被输入区覆盖。
- 表格输入即时更新，400 ms 延迟保存；显式保存、离开时刷新草稿。存储失败保留本次输入并显示恢复提示。
- 普通工作区最多保留两个，未保存或运行中的工作区保留；任务轮询减少完整项目重复刷新，后台页面降低频率。
- 按需加载模型设置与成文核对模块，拆分 React 依赖包。

设计约定见根目录 PRODUCT.md、DESIGN.md。没有增加项目归档、最近项目分组或全面重写核心类型；旧 CSS 尚未完整迁移，已在 DESIGN.md 记录差异。
