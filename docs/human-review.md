# 首次体验与真实验收

1. 在当前 PowerShell 运行 `scripts/start.ps1`，打开本地页面并用启动令牌登录；此入口在 Codex 关闭后仍由 Python 服务运行。
2. 填写本项目已授权的 DeepSeek Key；设置最多调用次数、输出预算，先做连接测试。若使用图片，配置视觉模型并运行合成图片能力测试。
3. 用原包 `examples/evaluation_cases.json` 中 EV-01 的 materials 文字创建项目。不要把 frozen_known、must_remain_unknown、forbidden 或本评测说明粘贴给被测应用。
4. 授权当前接收端与选定材料，执行理解和澄清；核对“只读不能修改”“重叠拒绝后原数据不变”是否保留，相接边界/跨午夜/精度是否仍待确认。
5. 回答问题，选择本期条目，生成页面方案；切换正常、加载、空态、错误、无权限状态。模型未明确的规则应可见，模拟数据不能被称作产品实现。
6. 默认生成 PRD，再按需生成同版 MRD；检查规范原文、合理精简、重要未知、原型图与参考章节处置。实际导出的新文档仍要打开检查。
7. 运行多视角审查，解决或缩减范围内阻塞项，核对确认页后点击指定版本确认；下载前后端与验收包。
8. 修改一条规则，核对旧基线和旧包保留，新内容不能复用旧确认。重复 EV 时新建隔离项目，保留每一次结果。

每个 EV 记录：项目/run ID、输入哈希、Provider origin、请求/响应模型、调用与 usage、修复次数、材料范围、产物哈希、模型输出、实际语义发现、人工结论。不要只记录最好的一次。

状态建议：工程实现、真实调用、语义效果、真人内容确认分别填写。未做的一律 NOT_RUN；没有真人明确认可时不能写 DONE。
