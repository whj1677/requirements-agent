## 使用

本机交付使用独立目录、独立 data 和 8766 端口。原 8765、原数据库及历史试跑保持不变。双击交付目录的 `start-local.cmd`，或运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Port 8766 -NoAuth`。

分发 ZIP 不含 Python/Node、依赖、业务数据或密钥。新机器需已安装 Python 3.11+、Node.js 20+；首次运行 `scripts/install.ps1` 安装依赖。ZIP 已附前端构建。当前本机安装复用既有 Python 依赖。

在交付目录根目录创建 `.env`，配置 `RA_DEEPSEEK_API_KEY=你的密钥`。不要上传该文件。模型设置显示配置状态；没有 Key 仍可整理材料、查看已有内容。模型任务启动前核对材料、接收端和请求上限。

建议顺序：描述目标/添加资料 → 整理当前信息 → 回答确实未知的问题或先看方案 → 选择讨论方向 → 查看和修改原型 → 核对本期条目 → 生成讨论稿 → 查看并下载 Word。选择方向不会自动采纳关联假设。讨论稿允许保留未知，正式确认继续使用原服务端门禁。

## 备份与恢复

结束当前任务后，关闭此交付实例，再备份整个 `data` 目录（数据库、sources、证据和导出必须一起保留）；`.env` 单独在本机私密备份。不要只复制运行中的 SQLite 主文件。

恢复时解压程序到新目录，把备份 data 放入该目录，单独恢复 .env，再使用空闲端口启动并核对项目名、版本、来源及产物。先在副本验证，不覆盖正在用的目录。模型凭据不进入分发 ZIP 或公开仓库。

构建 ZIP：`python scripts/package_local.py --web-dist <隔离构建目录> --output <新的输出目录>`。工具只纳入 Git 已跟踪源码及指定前端资源，排除本机数据和配置。
