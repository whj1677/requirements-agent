# 参考产品对标与需求草稿填充（2026-10-04）

## 任务范围与停止条件

本轮目标是复验阻塞点处理路径，并在现有需求助手阶段增加资料或公开网址对标入口，复用已有读取、任务授权、候选生成和阶段跳转。有限交付为源码、回归、唯一工作台更新及操作说明；达到相关测试、完整离线回归、生产构建和实际页面入口核对后收口。

测试使用隔离项目与本机合成模型。日常用户项目仅用于导航、读取、准备任务范围及取消，不修改、采纳或确认其业务内容。真实付费模型、用户业务验收、安装包、Git 提交及正式发布不在本轮执行范围。

## 操作与结果

1. 第一步“聊清需求想法”展开“对标参考产品”，填写对象和参考范围。
2. 添加参考文件、截图、文字并检查读取状态，勾选资料；或填写公开 HTTP(S) 网址，确认有权读取后读取单页。聊天提到参考对象或网址时显示入口提示，不擅自抓取。
3. 点击“对标并填充需求草稿 →”，核对本次任务范围并授权模型任务。弹窗显示指定参考对象、选中资料以及本轮其它项目上下文；选择对标资料不代表只发送这些资料。
4. 成功生成草稿后沿用整理任务的自动跳转进入第二步。对标分析分为参考做法、已知差异和候选建议，附原文及来源、候选处理入口、读取限制。人工核对修改或采纳后继续下一阶段。

已填写字段和聊天原话保留；自动生成需求、规则、验收及业务行为候选不等于自动采纳或完成后续阶段。未知业务规则和数值不补造，差异未知留空。模型没有给出足够可验证内容时保留限制或拒绝激活，不能声称完成分析。

资料选择显示用途、读取状态与可展开的内容片段，避免多份同名“对话输入.txt”无法区分。勾选指定参考资料不会改写原有资料用途。

## 来源与授权约束

- 只有当前项目的有效资料可以用于对标，排除、替代、模板、工程上下文和没有可用内容的来源不能冒充参考资料。
- 文本观察必须绑定本轮实际送入的指定来源片段，引文是连续原文。图片引用当前视觉运行中来源、片段及读取身份一致、且未标为不确定的观察；像素占位文字不是图片理解结果。视觉观察在页面另行标注、仍需人工核对。
- 竞品资料与“想对标”的任务输入不能独自证明本产品现状或已决定采用。只由这些材料支撑的候选不能变为已报告的业务决定；后续任务继续保留此约束。
- 任务范围、资料和当前修订由现有计划哈希绑定。新增对标输入需要核对发送范围，即使旧资料已获授权也不能绕过。真实模型任务只在用户授权后运行。
- 公开网址沿用既有公开地址、重定向和内网访问检查，不读取浏览器登录状态，不递归抓取站点；失败不会被自动重试伪装为已读取。
- 资料版本改变或排除后报告标明需重新核对；候选入口依实际条目身份解析。浏览器草稿保护保留对标字段、来源选择和网址，恢复不复用网页读取同意。
