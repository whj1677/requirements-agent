# 导航与表格交互修复（2026-10-11）

## 已解决的问题

- 正式确认中的 MRD/PRD 卡片打开各自文档；任务记录的文档结果会展开文档区域，审查结果会定位当前版本审查。
- 需求表未变化且原确认仍有效时，顶部步骤与底部“返回交付”只执行导航，不重复提交确认。判断包括持久内容、原确认哈希、需求来源/版本有效性；本地保存、刷新恢复和新 AI 填入均不能代替人工确认。
- 文档页及前序阻塞使用“提供信息 → 完善需求 → 确认交付”三个步骤的名称；后端检查点和提交参数保持原义。
- 交付概览中的章节讨论问题交给统一定位逻辑，在对应文档页处理。
- 矮桌面窗口压缩标题、步骤、状态和工具区域，为表格保留更多空间。保留表内滚动、错误提示、可调整输入框和固定底部操作。
