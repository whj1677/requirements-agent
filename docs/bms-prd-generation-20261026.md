- “先生成待确认评审稿”直接使用已保存内容，通过既有 PRD 编译器生成正文、字段表、交互表、流程、状态及验收；不再为重复排版调用模型。生成保留来源、问题、条款及检查快照，并留下独立的本机任务、产物与幂等回执。

- 此入口只接受当前有效的成文检查；失败、过期、硬性引用/结构问题、活动任务、无有效来源及过期版本仍被拒绝，失败不产生半份文档。
- 本轮检查涉及的旧验收直接显示，不再被“默认收起未改内容”隐藏。
- 文档提示改为“正式交付前需处理”，明确当前评审稿可读、可下载。文档区显示本次本机生成状态，不沿用此前“尚未生成新版 PRD”的旧模型任务提示。
