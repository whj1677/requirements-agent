# PRD 章节讨论原地处理修复（2026-10-11）

## 复现与边界

电价管理 `P-d4b61a83e6f14612` 的 PRD“使用者与权限”章节讨论“运维人员”后，v23→v24 增加一个角色候选和一个权限问题。原 10 条需求确认仍有效，PRD 正文未变；但新增问题使业务规则阶段需要核对，原入口将用户带回整个“完善需求”表格。

另一个独立问题：v21 生成 PRD 后，重复整表确认得到 v22，业务内容完全相同，仅核对时间、预览及回答绑定元数据改变，却使 PRD 输入哈希变化。

## 修复

- 文档页显示与本篇章节讨论精确关联的问题，回答、关联规则修改预览、人工确认在原处完成。前序核对入口在实际阻塞均属于本篇讨论时定位当前补充；无关缺项仍保留自己的处理入口。
- 保存原话和确认业务修改仍分开；阶段条件全部满足后，人工点击“确认本次补充已处理”，继续核对文档。不重复确认全部需求，不自动生成或批准文档。
- 文档讨论和后续针对问题的局部澄清保留全局摘要建议及引用。执行记录保存讨论目标及实际新增条目/问题 ID；旧记录仅使用任务、执行审计中的真实 ID 回溯。
- 重复整表确认先执行完整校验，再复用绑定完全一致的核对记录。真实正文、验收、答案、摘要、来源和版本变化仍会使相关产物失效。
- 保存失败保留输入；切换文档和任务结果导航先处理未保存修改。
