# 完善需求的笔记本布局优化

优化前代码已本地归档为 `c0a9b76`。本次只调整完善需求页面的布局、定位和展开方式，保留整表保存、原文核对和显式确认的业务逻辑。

- 有效高度不超过 900px 时压缩导航与周边留白，操作按钮合并到标题区域。正文仍为原有 14px，不靠缩小输入文字增加空间。
- 待补充验收的数量保持可见，长说明按需展开。详细定义的字段、交互、流程与状态分组默认折叠，摘要显示条目数及待补充数；校验定位仍自动展开并聚焦。
- “定位需求”可以直接跳到指定需求的输入位置。
- “专注核对”临时收起项目侧栏、顶部项目栏与阶段导航；编辑表格保持挂载，退出后恢复原布局。
- 回答原文核对中的摘要随正文滚动，避免粘性摘要遮挡表头或输入。底部保存和确认按钮保留。
