## 架构决定

- FastAPI + SQLite，React/TypeScript + Vite；后端控制采纳、确认、版本及权限。
- 原包只读引用；版本化 JSON 快照保留历史，确认和导出追加记录。
- 单阶段调用，运行事件持久化；取消、格式修复和重试共享预算。
- 模型只写候选。人工编辑/采纳改变底稿；PRD 和 UI 派生内容另存并绑定底稿哈希，避免生成两文档时相互失效。
- 文档规范条款由引用解析原文；叙述区仍须语义评审及真人确认。
- 本机随机访问令牌换会话 Cookie，Origin/Host/CSRF 检查；环境变量或仅服务进程内存保存模型 Key。
- 本次按指定的 pm-req 工作区实现，不迁移到别处。
- 空工作区，不存在待迁移的旧数据库；读取历史 payload 时不改写哈希。
