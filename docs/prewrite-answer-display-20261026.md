# 成文检查推荐回答显示修复

## 原因与处理

BMS revision 48 的四个待确认问题 answer 均为空，旧检查结果没有推荐回答，仅有 suggested_resolution（修改指令），前端却统一标注“AI 推荐草稿”。不能把“请由 PM 明确”之类指令假装成完整业务回答。

- 确认表读取本轮批量草稿、检查项 recommended_answer 和已有单题 recommendation，自动填入可编辑回答；已保存回答优先，人工编辑和清空通过原有草稿合并机制保留。过期的批量回答不会回填新检查项。
- 历史检查缺少回答时，明确说明“本轮检查尚未生成回答草稿”，在原空白单元格内展示检查建议及一次批量起草入口，不再虚假显示已生成。
- 成文检查协议增加可选 recommended_answer，并在同一模型请求中要求返回完整具体推荐方案。建议仍保存在检查结果中，人工整表确认前不写作用户回答，不代替条款修订与复检。兼容旧输出，未返回该字段不会使整个检查中断。
- 修复共享条款的关联问题：某决定已被另一检查项明确绑定时，不再仅凭同一条款编号将它绑定给无关检查项。历史问答未被程序静默重写。
