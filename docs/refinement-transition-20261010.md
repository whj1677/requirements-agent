# 提供信息后自动整理并进入完善需求

“提供信息”中的主动作合并为“整理并进入完善需求”：保存当前工作底稿及项目语境，检查已有整理结果；有新信息时启动整理，可用结果完成后自动进入需求确认表。聊天、直接填写、顶部步骤和右侧进入按钮共用此路径。

- 信息未变时复用已完成的整理。人工确认、修订摘要及项目改名不触发重复整理。
- 聊天框未发送的文字或附件会明确提示先处理，不会被忽略。
- 新资料或新接收端仍使用已有任务授权弹窗；已有授权沿用。
- AI 只生成候选，不自动采纳条款、确认摘要或确定本期范围。
- 整理失败留在提供信息页；主动点击“重试整理”才能重新尝试。不确定的网络提交持久保存原请求键，先恢复同一任务。
- 切换项目或页面后，旧任务完成不会强行跳回。取消任务后不会采纳迟到结果。
- “不使用 AI，直接完善”保留专业用户的手工路径：保存输入后进入，不调用模型。

## 验证边界

后端准备状态、前端异步协调和隔离浏览器流程分别验证。浏览器使用真实页面及应用接口，模型响应使用冻结的合成储能云资料；不调用外部模型、不操作日常项目，不代表本轮完成了真实模型质量验收。

相关证据：

- `evidence/refinement-preparation-20261010/backend.xml`：准备状态、历史兼容和来源变化。
- `evidence/refinement-preparation-20261010/affected.xml`：既有任务、共享底稿与聊天摘要回归。
- `evidence/refinement-transition-20261010/coordinator.json`：双击、失败重试、未知网络提交、取消与切换。
- `evidence/refinement-transition-20261010/ui-regression.xml`：入口、附件、底稿和任务进度。
- `tests/check_refinement_transition_browser.py`：隔离浏览器验收及可选录屏。

日常工作台仍为仓库根目录 `http://127.0.0.1:8765/`。更新前备份并检查活动任务，不自动刷新用户已有标签页；新界面需要用户刷新该标签页。
