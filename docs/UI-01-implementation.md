## 实施结果（2026-09-23）

- A 工作台：已接入现有应用。React 按壳层、项目切换、讨论/成果、材料、文档、确认、版本和模型设置拆分；统一请求客户端保留会话、Origin、CSRF 与版本参数。项目切换隔离旧请求，活动任务才轮询。输入草稿按项目保留，中文组合输入期间不发送。
- B 工作台业务流程：材料仍按后端逐项记录读取状态；授权前展示接收端与材料清单。方案采纳前展示关联条目。文档有独立 PRD/MRD 阅读页、动态目录和旧版条目快照。确认先复核范围，再调用服务端哈希/范围门禁；409 保留复核对话框，不自动重放。
- C 业务原型：wireframe 1.1 增量支持抽屉、时间字段、筛选、新增/编辑、白名单校验与模拟保存；1.0 继续可读。模型输出仍经 Schema 与引用校验，沙箱渲染器只处理文本节点且 CSP 禁止连接。新布局作为服务端候选，采纳会形成新草稿并标记文档/审查待更新；拒绝保留旧页面。电价区间和联系人是两类独立工程夹具，未写入通用渲染器或空项目。
