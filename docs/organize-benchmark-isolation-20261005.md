## 已核实原因

普通 `organize` 任务没有对标请求，生成 schema 却允许 `benchmark_analysis`。首轮输出该字段的精确空壳，同时有另一未知占位字段；格式修复因对标摘要的非空约束补成“没有竞品资料”的说明，程序随后又按未请求对标而拒绝。三次请求均未写入业务草稿；这不代表用户缺少必填对标资料。

原始调用证据完整保留，具体身份与重放结果只保存到忽略的 `evidence/organize-benchmark-isolation-20261005/`，不在本说明复制业务原文。

## 修复结果

- 普通生成请求及其格式修复不再提供对标输出字段，显式对标仍保留完整契约及引用检查。共享校验器不被单次请求修改。
- 兼容旧空模板时，仅允许移除精确的空摘要、空观察、空限制对象；原始模型响应不改写，额外记录处理规则及处理前后摘要哈希。其它未知字段、业务原文、问题、来源及修复保真检查继续执行。
- 未请求却生成非空对标内容时，拒绝写入，并停止后续自动格式修复，避免继续为同一错误消耗请求。
- 失败提示明确说明无需补充竞品资料，提供“前往需求草稿”入口；已有内容保持可编辑，后续必需核对仍受阶段约束。已经在草稿页时不再显示原地跳转按钮，进度面板失败状态改用警示色。
- 重试仍先展示本次任务范围，再由用户运行；不把修复代码或只读重放当作历史任务成功。
