## 范围与完成边界

本轮处理真实对标任务未写入、失败网址缺少恢复入口、令牌阻止进入三个问题。交付为现有代码修复、离线回归、同一工作台更新和一次新真实模型复测。资料采用既有独立验证项目中的公开摘要及短引文；没有发送原“学习助手”项目的材料。

停止条件为：能直接进入工作台；模型输出经校验成为可审核候选；页面自动进入草稿核对；失败来源能找到恢复操作；原有业务数据保持。没有代替用户采纳、回答业务问题、建立基线、生成正式文档或发布安装包。

| 模型在根对象未写完时多输出一个关闭括号 | 仅对 ingest 阶段的一种明确结构进行确定性恢复：后续字段必须是允许的、完整且不重复的根字段，所有解码值保持，完整 Schema 仍须校验；原始模型回复保留。截断、重复字段、未知字段及嵌套错误继续拒绝。 |
| 一次只报告首个引用错误，模型修复容易遗漏其他问题 | 合并报告对标候选引用、悬空关联及复合问题；明确候选与问题的引用类型。修复必须保留对标观察、有效引用及原文，只能移除无效链接；无法形成可靠锚点时明确拒绝，避免内部异常。 |
| 首次试跑自行设为 1 次请求，阻止了已有修复路径 | 新复测使用正常配置，没有额外设置 1 次请求上限。自动修复仍有程序限定的次数；本次回复首轮即被接受，实际未发生模型重试。 |
| 网址 403 后不知道在哪里继续 | 失败资料不可选择，显示原因；提供“去粘贴网页正文或添加其他资料”和“使用已选资料继续（移除本次网址）”。粘贴入口带出网址、保留已有输入并聚焦，手工资料与自动抓取身份分开。 |
| 本机访问令牌错误 | 日常启动不生成访问令牌，前端直接连接工作台；连接失败可重试。保留本机监听与写操作的来源、CSRF 校验。模型接收端密钥配置不受影响。 |
