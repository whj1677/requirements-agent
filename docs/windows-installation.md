# 需求 Agent：Windows 安装与模型配置

适用于 Windows 1.2.2 及本次客户试用包。该版本已取消设备许可证与激活校验，安装后即可打开工作台，不再需要申请或导入许可证。客户自行提供模型 API Key，并承担模型服务商收取的费用。

## 1. 安装前准备

- Windows 10 / 11 x64，使用日常工作的 Windows 用户账户。
- 从交付方取得 `RequirementsAgent-1.2.2-windows-x64-setup.exe`，核对随包 SHA-256。
- 包内包含 Python、界面、材料解析依赖、Playwright 驱动和 Chromium；不用另外安装 Python、Node.js、npm 或开发工具。
- 远程模型和公开网页读取需要网络；模型服务需使用客户自己的接收端与 Key。

安装包不包含 Microsoft Office。普通 DOCX、XLSX、PPTX 等材料先由内置解析器读取。旧格式或企业保护文件，可能需要本机已经安装、激活且获准使用的 Office 只读提取。提取时禁用宏、不更新外部链接、不保存或改写原件，不绕过企业保护。

Office 后备读取需企业允许本机 PowerShell 执行随包只读脚本：优先使用已安装的 PowerShell 7，否则用 Windows PowerShell 5.1；程序不改变执行策略、不添加 Bypass 参数。具体支持情况取决于 Office、文件权限与企业策略，必须用代表性材料实际核对。上传成功或人工能打开，都不等于程序已经读到内容。

## 2. 安装和首次打开

1. 双击安装程序，按向导安装到当前用户。默认目录为 `%LOCALAPPDATA%\Programs\RequirementsAgent`。
2. 从桌面或开始菜单打开“需求 Agent”，浏览器直接进入 `http://127.0.0.1:8765/`。
3. 点击左下角“模型设置”，配置服务商、模型和自己的 API Key。
4. 创建需求项目，描述目标并导入有权使用的材料。五步业务操作见 [用户使用说明](user-guide.md)。

升级用户原来的 `/activation/` 书签会返回工作台。旧许可证文件不再读取、校验或要求更新；新包也不携带设备授权组件。

## 3. 模型设置

“模型设置”页的“基础配置”可填写接收端 Base URL、模型名称和 API Key。输入 Key 后点击“保存配置与密钥到此电脑”；只修改模型参数时点击“保存接收端与模型”。默认主模型接收端为 DeepSeek；如果使用其他服务商，填写该服务商提供的兼容地址、模型标识和相应 Key。

Windows 客户版支持将 Key 保护后保存到当前电脑、当前 Windows 用户的凭据存储，重启后可继续使用；也可选择只在当前服务进程临时使用。Key 不随项目导出或安装包发送，换电脑或 Windows 用户后需重新输入。高级模型参数仍可按需要展开。

点击“测试连接（调用模型）”会真实请求模型，可能产生费用。没有 Key 时不能调用付费模型。取消设备许可证不改变材料外发确认：每次任务仍须核对接收端与本次材料范围。

如果此前在 `%LOCALAPPDATA%\RequirementsAgent\.env` 中配置过 `RA_DEEPSEEK_API_KEY`，仍可使用；该文件是用户自己的明文凭据，应保护好访问权限，不要外发或提交 Git。

## 4. 日常使用与退出

- 工作台固定使用 `http://127.0.0.1:8765/`。重复打开快捷方式复用同一实例，不自动换端口。
- 退出前保存输入，点击左下角“退出工作台”，再点“确认退出”。未保存内容会先提示处理；有模型任务或材料读取时会拒绝退出并提示等待。
- 页面收到退出确认后，等待数秒再关闭页面、升级或卸载。只关闭浏览器标签页不会停止后台服务。
- 若提示 8765 被占用，正常退出原工作台后再打开；不要按进程名批量结束 Python、Office 或浏览器。

## 5. 数据、升级和卸载

| 内容 | 默认位置 |
| --- | --- |
| 程序与依赖 | `%LOCALAPPDATA%\Programs\RequirementsAgent` |
| 项目、附件及业务成果 | `%LOCALAPPDATA%\RequirementsAgent\data` |
| 受保护的模型凭据 | `%LOCALAPPDATA%\RequirementsAgent\data\.credentials` |
| 运行日志 | `%LOCALAPPDATA%\RequirementsAgent\logs` |
| 旧版可选明文模型配置 | `%LOCALAPPDATA%\RequirementsAgent\.env` |

升级前保存输入、结束任务并正常退出。确认服务停止后，复制整个 `%LOCALAPPDATA%\RequirementsAgent` 到受保护的备份位置。备份可能包含业务材料与凭据，不要外发。不要在程序运行时直接复制 SQLite 文件充当一致性备份。

运行新版安装程序可更新原安装。安装器仅清理程序目录内已停用的授权组件和激活页面，不删除用户目录中的旧许可证、项目或配置。卸载也会保留该用户目录；同一 Windows 用户重新安装后仍可读取已有项目。

恢复时先停止程序，单独核对备份并保留原目录用于回滚，不直接合并不同时间的同 ID 项目。安装包不能代替项目备份。

## 6. 常见情况

| 情况 | 处理 |
| --- | --- |
| 没有模型 Key，分析无法运行 | 在左下角“模型设置”配置自己的接收端、模型和 Key。 |
| 仍看到旧激活页面 | 确认已关闭旧服务并安装 1.2.2；重新从快捷方式打开。旧页面不会自动变成新版本。 |
| 8765 端口已占用 | 保存并正常退出原工作台，再启动本版。 |
| Office 材料读不到内容 | 核对读取状态、本机 Office 与企业权限；普通解析失败不等于原文件损坏。 |
| 安装时提示程序运行中 | 先在工作台正常退出；安装器不会强制结束进程。 |

应用和安装器当前未做商业代码签名；请通过交付来源与 SHA-256 核对文件身份。离线安装与合成材料测试不等同于真实模型文档质量验收或所有企业电脑环境兼容。
