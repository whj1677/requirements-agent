# 文件支持与缺项定位（2026-10-20）

本次补齐本地 HTML/HTM 读取和各上传入口的格式说明，保留已有 PDF、PPT/PPTX 读取链路，不增加模型调用或自动外发。

- PDF 按页提取文字并保留页码。混合扫描页会说明未取得文字的页；纯扫描或有密码的 PDF 不标记为已读取，不自动执行 OCR。
- PPTX 使用内置解析器读取正文与表格等可提取内容；未读取的对象继续说明限制。旧版 PPT 使用既有本机 Office 只读后备路径，需要已安装且获准使用的 PowerPoint。
- HTML/HTM 提取静态正文与标题，保留段落定位，不执行脚本、不访问引用的外部资源。脚本生成内容、图片和嵌入对象保留未读取说明；只有标题或脚本的文件不标记为内容已读。
- 聊天文件选择、拖放校验、上传 API、项目资料能力列表和文件选择器保持一致。未发送的聊天附件保留在本地；读取不等于允许向模型发送。

在完善需求点击顶部“确认交付”时，会检查当前本地草稿并定位首个缺项；展开对应分组、滚动并聚焦可编辑控件，保留其他输入。全部必填内容补齐后仍需用户明确确认表格，不因跳转直接确认。

“保存并继续核对”成功但仍有回答未落实时，直接定位到答案原文选择控件。正式确认按钮在存在缺项时保持可操作，点击后沿实际阻塞对象定位到字段、问题、资料、文档或审查入口，不提交确认、不建立基线、不自动选择答案见证。当前文档核对的继续动作沿用同一实际阻塞定位。

验证证据位于忽略目录 `evidence/file-navigation-20261020/`。使用隔离应用、合成文件和单一正式源地址的请求拦截，不启动额外工作台、不写日常项目数据。真实模型、客户企业保护材料及第二台物理电脑不属于本次验证结果。
