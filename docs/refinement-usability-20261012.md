# 桌面需求核对优化（2026-10-12）

根据本轮 Impeccable critique 的实际问题，用户要求暂不处理窄屏，其余四项做最小优化。沿用现有界面与确认流程，没有调整后端业务规则。

- 表格新增项目摘要、需求与验收、待落实回答、关联规则的定位入口，以及上一项／下一项待落实。定位直接聚焦回答输入框，跳过已完成原句选择的回答；次要业务说明默认折叠，需要时展开，原值和确认输入保留。
- 原句位置选择前可展开非空字段的摘要。选择位置只展示完整原句，核对复选框仍由用户勾选。核对区域展示当前问题和回答摘要，减少跨区域记忆。
- 导航提示、底部按钮和保存说明使用同一状态文案。待落实时显示「保存并继续核对」，草稿保存明确限定当前浏览器；返回核对只定位，不刷新或提交。
- 章节沿用原文时使用「预览本次落实核对」，预览说明正文沿用原文；有实际条款修改时仍显示修改预览。最终确认依然单独执行。
